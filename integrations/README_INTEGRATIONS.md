# KhetLoop integrations (P4)

Python modules the backend calls directly. Every function returns the standard envelope
`{"ok", "data", "data_source", "error"}` and never raises.

| Module | Functions | Data source labels |
|---|---|---|
| `weather.py` | `get_forecast(lat, lng)` | `live`, or `cached` if Open-Meteo is down |
| `speech.py` | `stt(audio_path, lang)`, `tts(text, lang, out_path=None)` | `live` |
| `prices.py` | `get_mandi(crop, market)` | always `cached` (see limits) |
| `reminders.py` | `schedule(report_id, hours, message=None)`, `run_due(send_message)` | `live` |

## Setup

1. Python 3.12 or 3.13 is recommended (the team currently runs 3.14, which also works).
2. Create the venv and install: `python -m venv .venv`, then `.\.venv\Scripts\Activate.ps1`,
   then `pip install -r requirements.txt`.
3. Install ffmpeg: `winget install Gyan.FFmpeg`, then reopen the terminal and run `ffmpeg -version`.
   Telegram voice notes (`.oga`) are converted to wav with ffmpeg before Groq sees them.
4. Copy `.env.example` to `.env` and fill the keys your module needs (below). Never commit `.env`.

## Environment variables used by integrations

| Variable | Used by | Notes |
|---|---|---|
| `GROQ_API_KEY` | `speech.py` | Required for Kannada/Hindi/English speech-to-text |
| `SPEECH_PROVIDER` | `speech.py` | Set to `groq_gtts`. Also accepts `gemini_gtts`, which uses the same Groq code path today |
| `TMP_DIR` | `speech.py`, `weather.py`, `tts` | Default `./tmp`. Holds temporary audio and the weather cache |
| `DB_MODE` | `reminders.py` (through P2's `db_client`) | `memory` for development, `supabase` in the live system |

Gemini is not used by the integrations today. Gemini audio speech-to-text is not implemented.

## Speech (speech.py)

- Speech-to-text: Groq `whisper-large-v3`, with `whisper-large-v3-turbo` as a fallback.
  The primary call gets a neutral vocabulary hint (no severity words) that fixed Hindi and
  Kannada spelling errors in testing.
- Junk guards: audio quieter than -50 dB is never sent to Groq. Transcripts are rejected when
  the average log-probability is below -0.40, the no-speech probability is above 0.5, or one
  word repeats most of the transcript. Thresholds were tuned on 12 clips.
- Text-to-speech: gTTS (Google, online). It needs internet.

Test results so far: clean Kannada, Hindi and English clips transcribe well, with occasional
spelling errors. A noisy Kannada clip was also recognised. Silence and noise-only clips are
rejected. Only a few clips have been tested, and nobody on the team has tested a noisy field
recording. Treat this as "works on clear speech", not "works on any farm recording".

## Weather (weather.py)

- Open-Meteo forecast, no key needed, 8-second timeout.
- `rain_expected` is true when the 48-hour total is at least 1.0 mm.
- Successful results are cached per rounded location in memory and in `tmp/weather_cache.json`.
  If Open-Meteo is down, the last cached result is returned with `data_source: "cached"`.
- Only rounded coordinates are sent. Farmer names and exact locations are never logged.

## Mandi prices (prices.py)

- Data comes from `data/mandi_cache.json`. It holds real modal prices copied from a third-party
  site that republishes government mandi data. These are not live prices.
- Every result is labelled `cached` and shows its date. Verify before using them for decisions.
- Covered: tomato (Srinivasapur, Bangarpet, Kolar) and potato (Kolar, August 2026, so it is old).
- Not covered: chilli. Unknown crop or market returns a clean failure.

## Reminders (reminders.py)

- `schedule` saves a reminder through P2's `insert_reminder`.
- `run_due(send_message)` sends each due reminder through the callback `send_message(chat_id, text) -> bool`.
  After a successful send it marks the reminder sent, adds a `follow_up` event (actor `system`),
  and sets the report status to `follow_up` (contract C9).
- A failed send is not marked sent and stays pending. A farmer with no `telegram_chat_id` is
  counted as failed.

## Test data (data/)

- `approved_guidance.json`: non-chemical guidance in English, Hindi and Kannada. The Hindi and
  Kannada wording is a draft and must be checked by a native speaker before the demo.
- `data/seed/`: 8 farmers, 8 farms and 14 reports, 30 rows in total, all simulated. Generated by
  `tests/integrations/make_seed.py` from `approved_guidance.json`. Re-run it after editing guidance.
- `data/test_images/`: 8 PlantVillage-derived photos and `LABELS.csv`. Attribution is in the CSV.
  The labels are the dataset's labels, not confirmed diagnoses. PlantVillage photos are lab-style,
  so they do not show field accuracy.

## Running the checks

```powershell
python -m pytest tests/integrations -q           # offline unit tests (131), no internet or keys
python -m integrations.selftest                  # quick offline checks for every module
python -m integrations.selftest --live           # also calls Open-Meteo, Groq and gTTS
python -m tests.integrations.check_reminders     # end-to-end reminders in DB_MODE=memory only
```

Manual tools in `tests/integrations/` (not run by pytest): `probe_stt.py` (compare STT models
and hints), `check_speech.py` (real STT and TTS on recorded clips), `make_test_images.py`,
`make_seed.py`.

## Known limits

- Speech accuracy is tested on a small set of clean clips. Farm noise, dialects and long notes are not tested.
- Kannada and Hindi guidance and reply wording are unverified drafts.
- Mandi prices are cached copies, not live data, and are partly old.
- Weather rain threshold (1 mm) is our choice, not from the contract.
- Image labels come from PlantVillage. They are not field-validated diagnoses.
- TTS needs internet access to Google.

## Contract points for other modules

- Reminders depend on P2's `db_client` functions. Use `DB_MODE=memory` for local tests.
- `TTS` errors use `INTERNAL_ERROR`, because the contract has no TTS error code.
- Seed rows have no `telegram_chat_id`, so reminders for seeded farmers are never sent.
